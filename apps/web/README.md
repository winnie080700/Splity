# Splity Web

Run `pnpm install` from the repository root, then start this app with `pnpm dev:web`.

Copy `.env.example` to `.env.local` and fill in the Supabase project URL, publishable key, and service role key before running the full Phase 1 smoke test. Legacy projects can use `NEXT_PUBLIC_SUPABASE_ANON_KEY` instead of `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`.
